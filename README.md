# Beam Them Back — builds

Pre-release Windows builds of **Beam Them Back**, by [Frogee Studios](https://frogeestudios.com/). A goofy 1950s
B-movie alien invasion: build by day, hold the doors by night, rescue the town. Solo or with up to three
friends. The game is coming to Steam; these builds are for friends and playtesters in the meantime.

## Download

**[BeamThemBack-Setup.exe](https://github.com/scottrojee/beam-them-back-builds/releases/latest/download/BeamThemBack-Setup.exe)** — always the newest build.

Windows will warn that the installer is unsigned: click **More info**, then **Run anyway**. The game checks
for a newer build every time it starts and offers to update itself from the title screen, so you only need
this link once.

Prefer no installer? The same build is on the [latest release](https://github.com/scottrojee/beam-them-back-builds/releases/latest)
as `BeamThemBack-win64.zip`. Unzip anywhere and run `BeamThemBack.exe`.

## Playing with friends

- **HOST ONLINE** on the title screen gives you a six-character code. Friends type it into **JOIN** on theirs.
- **HOST LAN** works on the same network, or over Tailscale, with no code.
- Everyone needs the same build. If versions differ, the game says so on join and points at the link above.
- If the host quits, the run ends for everyone. There is no host migration yet.

## Requirements

Windows 10 or 11, 64-bit. Measured on an RTX 4060 Ti at 1080p on Medium: over 200 fps in a four-player
fight. Slower machines have not been tested yet; the settings menu has a Low preset and resolution options.

## Feedback and bugs

Email [contact@frogeestudios.com](mailto:contact@frogeestudios.com), or tell us in person. Saying which build
you were on helps: the version is in the corner of the title screen.

Nothing is collected unless you say yes on the first-launch consent card. The full policy is at
[frogeestudios.com/privacy](https://frogeestudios.com/privacy/).

## Renamed from Holdfast

This game was called *Holdfast* until September 2026, and this repository was `holdfast-builds`. Old links
still work: GitHub redirects them, and every release also ships `Holdfast-Setup.exe`, the same installer under
the old name, so builds from before the rename can still update themselves.
